# Fonts

Place these TTF files here before running the app. They are referenced from
`app/_layout.tsx` and the typography system in `src/theme/typography.ts`.

- `PlayfairDisplay-Regular.ttf`
- `PlayfairDisplay-Medium.ttf`
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`

Both families are open-source on Google Fonts:

- Playfair Display — https://fonts.google.com/specimen/Playfair+Display
- Inter — https://fonts.google.com/specimen/Inter

Quick install:

```sh
npx expo install expo-font
# Then download the TTFs from Google Fonts and drop them in this folder.
```
