# Assets

Drop these image files here before publishing:

- `icon.png` — 1024×1024 app icon
- `splash.png` — splash screen (Expo will fit it on a `#FAF7F2` background)
- `adaptive-icon.png` — Android adaptive icon foreground (1024×1024)
- `favicon.png` — web favicon

In production, replace the Unsplash placeholder URLs in
`src/data/products.ts` and `src/data/categories.ts` with the studio's own
photography (CDN-hosted or imported from `assets/products/...`).
